# Ossuary (hobby prototype)

Isaac-style roguelike set in Eda, built with three.js and Tripo3D models.

## Setup on Windows

1. Install Git for Windows and Node.js (LTS).
2. Install Claude Code in PowerShell: `irm https://claude.ai/install.ps1 | iex`
   (or use the Code tab in the Claude desktop app).
3. Unzip this folder, open PowerShell in it and run:
   ```
   git init
   git add .
   git commit -m "Prototype 0.3 handoff"
   claude
   ```
4. First prompt: `Read CLAUDE.md and complete milestone M0. Start with a plan and wait for my OK.`

`prototype/ossuary-0.3-playable.html` opens directly in a browser and is the reference for the port.
